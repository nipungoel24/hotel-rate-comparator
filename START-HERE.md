# Hotel Rate Comparator Planning Package

This is the requested project blueprint and agent prompt. It is not a runnable code submission.

1. Read Plan.md for the project explanation and build sequence.
2. Read the five governing files: PRD.md, Architecture.md, Rules.md, Phases.md, Design.md.
3. Paste or attach MasterPrompt.md to your coding agent. It is self-contained and embeds all five proposed specifications.
4. The agent should complete Phase 0 and ask for approval before scaffolding.
5. For later sessions, use ShortStartPrompt.md with the documents present, or explicitly authorize the next approved phase.

Memory.md is deliberately absent. Its creation/update protocol is defined in Rules.md and begins after the first implementation task. The application's README.md, scripts, tests and GitHub repository will be created during the implementation phases, not claimed as delivered by this planning package.

Sources.md contains the reviewed source links and the remaining revalidation requirements. No application tests were run because no application was built in this planning task.
