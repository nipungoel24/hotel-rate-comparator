Notes:

- The skills were read from the upstream repositories at `main` (raw.githubusercontent.com) on 2026-09-07; they are task-scoped guidance, not installed runtime dependencies. No agent-skill packages were added to `package.json`.
- Only the shadcn components actually used (button, input, label, card, alert, badge, skeleton) were added; the generated `button.tsx`/`input.tsx` were adjusted to Design.md (44 px controls, 8 px control radius, explicit transition properties, 12 px panel radius in the theme).
- Morphicons renders the real search→cancel morph in the browser (Playwright-verified flow); a static test stand-in is used only in the jsdom component suite (`tests/web/morphicons-stub.tsx`, documented there).
- theSVG asset provenance and SVG safety review: `docs/third-party-assets.md`.
